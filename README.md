# GEP public progress feed

A deliberately curated public implementation ledger for the Generalized
Execution Platform announcement site.

This repository is not a mirror of the private implementation ledger and does
not contain platform source code. It publishes selected completed platform
boundaries and current claim ceilings only.

## Publication rule

Every update must be reviewed as an independent public disclosure. Do not copy
private status documents wholesale. Do not include application-specific work,
private repository coordinates, internal review links, secrets, credentials,
datasets, or operator evidence.

Published as `kasselvania/gep-public-status` and consumed by
[gep.peterkassel.com](https://gep.peterkassel.com).
